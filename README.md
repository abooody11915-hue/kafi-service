# KAFI Service

منصة صيانة مستقلة Greenfield. لا تعتمد على Lovable أو قاعدة KAFI/KAFI 2، ولا تحتوي أي بيانات قديمة.

## مبادئ غير قابلة للتفاوض

- Supabase Auth هو مصدر الهوية، وجداول العضوية هي مصدر الصلاحيات.
- RLS حاجز البيانات النهائي، ولا تعتمد الصلاحيات الحساسة على واجهة المستخدم.
- انتقالات الطلب الحساسة تتم عبر Commands/RPC مع سجل أحداث وIdempotency.
- المبالغ تحفظ بوحدة الهللة، والفاتورة النهائية ودفتر القيود هما مصدر الحقيقة المالية.
- جميع المستندات والوسائط خاصة وتُعرض بروابط موقعة قصيرة العمر.
- بيانات التطوير اصطناعية فقط.

## تشغيل محلي

```bash
npm install
cp .env.example .env.local
npm run test
npm run build
```

يبقى التطبيق في وضع تأسيسي آمن إذا لم تُضبط متغيرات Supabase.

## الحدود الحالية

هذه المرحلة تنشئ الأساس: الهوية، الشركاء، المزودون والتوثيق، الكتالوج، الطلب وسجل أحداثه، الفاتورة، دفتر القيود والتسوية. المدفوعات وStorage وEdge Functions وواجهات الأدوار تأتي كمهاجرات ووحدات مستقلة بعد إنشاء مشروع Supabase الجديد.
